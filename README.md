# LiD – Leben in Deutschland / Einbürgerungstest trainer

Single-file visual trainer for the German citizenship / "Leben in Deutschland" test
(300 general + 10 Brandenburg questions, official BAMF catalogue Stand 05/2025).

- `index.html` – the trainer (Learn / Quiz / Mock exam / Mistakes / Cheat sheet / 10-day plan). Progress is saved in the browser.
- `map.html` – the verified trigger → key map (SPOT word in the question → PICK word in the correct option).
- `cheat-sheet.pdf` – printable version.

Published with GitHub Pages from the `main` branch root: https://obay-adam.github.io/lid/
